# MIORA Information Architecture

## Primary Navigation
- People (`/people`)
- Settings (`/settings`)

## People Flow
People Home
→ Add Person
→ Person Detail
→ Remember
→ Optional Add Context
→ Thought Timeline

## Lifecycle Flow
Person Detail
→ Archive
→ Archived People
→ Restore
or
→ Request Permanent Deletion
→ Deletion Pending
→ Day 5 reminder
→ Day 15 confirmation available
→ Permanent deletion

## Key UX Rule
The "Remember" action is always visually prominent on a person-related screen.
