# MIORA UI/UX Design Package

**MIORA — For the ones on your mind.**

This package translates the approved visual direction into a practical frontend structure.

## Included
- Original generated UI/UX master board
- Cropped reference screens
- Design tokens and Tailwind v4 theme
- Page structure
- Component breakdown
- Information architecture
- Route map and navigation links
- Style and alignment guidance

## Recommended Stack
- React + TypeScript
- React Router
- Tailwind CSS only
- Lucide icons (or another consistent thin-line icon set)

## Main Navigation
- `/people`
- `/settings`

People is the primary experience. Archive and deletion are secondary flows.

## Important
The cropped images are visual references from the approved master board. They are not production UI assets such as individual avatars or photographs. Replace those placeholder visuals with your own licensed/generated assets when implementing the application.
