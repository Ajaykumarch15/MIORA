# MIORA Style Guide

## Visual Character
Calm, intimate, premium, people-first, emotionally warm.

## Color Usage
- Charcoal: primary text and dark navigation
- Mist / Steel: atmospheric backgrounds and secondary surfaces
- Pale Snow / Frost: main surfaces
- Coral Accent: primary actions and remembrance emphasis

## Typography
- Display moments: Playfair Display
- UI and body: Inter
- Use large, confident headings with generous whitespace

## Components
- Cards: soft radius, thin borders, restrained shadows
- Primary CTA: coral-to-warm emphasis, pill or rounded-rectangle
- Bottom sheets: large top corners and a visible handle
- Icons: thin-line, simple, emotionally neutral

## Alignment
- Mobile content padding: 20–24px
- Keep primary content left aligned
- Center only for emotional/focal moments such as onboarding and success states
- Use consistent vertical rhythm: 8 / 12 / 16 / 24 / 32px

## Avoid
- Dense dashboards
- Excessive gradients
- Heavy shadows
- Data-table layouts
- Too many simultaneous actions
